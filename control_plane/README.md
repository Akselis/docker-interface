# Control Plane

## Alembic migrations

Migrations are configured under `control_plane/alembic` and discover SQLAlchemy models from `control_plane/db/models`.

### Prerequisites

- `DB_URL` environment variable set to your target database URL.
- Install dependencies from the project root `requirements.txt`.

### Create a migration from model changes

Run from `control_plane` directory:

```/dev/null/commands.sh#L1-1
alembic revision --autogenerate -m "describe_change"
```

### Apply migrations

```/dev/null/commands.sh#L1-1
alembic upgrade head
```

### Roll back one revision

```/dev/null/commands.sh#L1-1
alembic downgrade -1
```

### Notes

- If no models exist yet in `db/models`, autogenerated migrations will be empty.
- Add model modules under `db/models` and ensure they inherit from `db.models.base.Base`.
